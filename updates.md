### Updates (Changelog)

#### **Version 1.0.0 - Initial Release**
- Released the first version of the **Task Cycle App**.
- Core Features:
  - **Task Cycle Automation**: Automatically resets tasks when all tasks in a cycle are completed, with a "Cycle Complete" message for user feedback.
  - **Dynamic Subtask Progress Bars**: Visualize task and subtask completion percentages in real time.
  - **Timeline Feature**: Tracks actions like task additions, completions, and edits with timestamps.
  - **Integrated Notes Panel**: Allows users to add, edit, and manage task-specific notes directly.
  - **Detailed Stats Dashboard**: Displays task progress through pie charts and other visual analytics.
- Responsive Design:
  - Optimized for both desktop and mobile devices.

---

#### **Version 1.1.0 - Improvements**
- Improved task reset logic for better performance on larger task cycles.
- Enhanced the **Timeline Feature**:
  - Added modal navigation for easier browsing of timeline entries.
  - Improved timestamp formatting for better readability.
- **Stats Dashboard**:
  - Refined pie chart visuals for better clarity.
  - Fixed a bug where certain tasks weren’t contributing to the overall progress calculation.
- UI Enhancements:
  - Updated button alignment for mobile and desktop to avoid overlaps.
  - Added hover effects to buttons for a more polished user experience.

---

#### **Version 1.2.0 - New Features**
- Added the ability to **save and load task cycles** from local storage.
- Introduced a **Clear Timeline Button** to allow users to delete old timeline entries.
- Improved animations for smoother progress bar updates.
- Customization:
  - Added a new option to set different task colors based on priority.

---

#### **Version 1.3.0 - Bug Fixes**
- Fixed a bug causing the "Complete" button to overlap with the "Add" button on smaller screens.
- Resolved an issue where subtasks weren’t updating the progress bar correctly when deleted.

---
