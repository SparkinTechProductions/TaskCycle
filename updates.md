## 🔹 Task Cycle: Mini (Mini Cycle) - Current Build

### Version 0.9.0 - Beta Release
- First public build of **Task Cycle: Mini** (also known as **Mini Cycle**).
- Core Features:
  - ✅ **Mini Cycle Lists**: Task lists that reset when complete, forming a recurring task cycle.
  - 🔁 **Auto Reset & Manual Reset** options with “Cycle Complete” animation and toast message.
  - 📊 **Progress Bar** and visual task checkmarks.
  - 📥 **Drag-and-drop** task reordering.
  - 🔔 **Reminders & Due Dates** (when Auto Reset is disabled).
  - 🚨 **High Priority** tagging and per-task bell toggle.
  - 🏅 **Milestone Badges** for 5, 25, 50, 75, and 100 cycles completed.
  - 🎨 **Theme Unlocks**:
    - 5 cycles: Unlocks "Dark Ocean"
    - 50 cycles: Unlocks "Golden Glow"
  - 📈 **Stats Panel**:
    - Total tasks
    - Completed tasks
    - Completion rate
    - Cycles completed
  - 💾 **Import/Export Mini Cycle Lists** (.mcyc format).
  - 🎮 **Mini Game: Task Whack-a-Order** (unlocked at 100 cycles).
