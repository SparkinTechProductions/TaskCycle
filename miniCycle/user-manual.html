📖 User Manual

🔹 Getting Started

Task Cycle: Mini is a lightweight task manager designed to help you track and reset tasks quickly. Here’s how to get started:

  • Click the Add Task button to create a new task.
  • Check off tasks as you complete them.
  • When all tasks are completed, the cycle resets automatically (if Auto-Reset is enabled).

⚙️ Features & Settings

✅ Auto-Reset

When enabled, tasks reset automatically once all tasks are completed.

⏳ Due Dates & Reminders

Set due dates for tasks and enable reminders to stay on track.

🔥 High Priority Tasks

Mark important tasks with the priority button.

📊 Statistics

Track your task completion rate and milestones.

❓ Frequently Asked Questions

How do I rename a Mini Cycle List?

Go to the Mini Cycle switcher and select the rename option.

What happens if I delete a Mini Cycle?

Mini Cycle cannot be recovered, so be careful!
